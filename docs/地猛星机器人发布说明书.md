# 地猛星 MSPM0G3507 四足机器人 — 发布说明书

> **版本**: 2026-06-16 | **作者**: 地猛星项目组 | **MCU**: MSPM0G3507 (Cortex-M0+, 32MHz)

---

## 一、项目概览

地猛星是一台基于 TI MSPM0G3507 的四足机器人，集成语音识别、OLED 显示、MP3 音频和舵机步态控制。

**核心功能**:
- 语音命令识别（CI1302 离线语音模块，无需联网）
- 1.3 寸 OLED 实时状态显示
- WT2003H4 MP3 模块音频反馈
- 4 路独立 PWM 舵机，非阻塞步态引擎
- 8 种机器人行为：前进/后退/左转/右转/坐下/站立/停止/跳舞/唱歌

### 2.4 电源分配

```
外部 5V 电源 (独立供电，≥2A)
    ├── 舵机 VCC ×4  ⚠️ 必须独立供电
    ├── MP3 模块 VCC
    └── 【不要接板卡 5V 排针！会倒灌烧毁电源】

板卡 3.3V (USB 或板载 LDO)
    ├── OLED VCC
    └── CI1302 VCC

所有模块 GND 必须共地
```

> ⚠️ **舵机必须独立供电**。4 个舵机同时动作峰值电流可达 2-3A，从板卡 5V 取电会导致电压跌落、屏幕掉电重启、MCU 复位等问题。

## 四、通信协议

### 4.1 CI1302 语音识别 (I2C)

| 项目 | 参数 |
|------|------|
| 接口 | 软件模拟 I2C (PB2=SCL, PB3=SDA) |
| 从机地址 | 0x34 (7-bit) |
| 识别结果寄存器 | 0x64 |
| 播报命令寄存器 | 0x6E |

**命令 ID 映射** (CI1302 出厂固化的语音词条):

| 语音口令 | 命令 ID | 功能 |
|---------|--------|------|
| "前进" | 0x01 | 向前走 |
| "后退" | 0x02 | 向后退 |
| "左转" | 0x03 | 原地左旋 |
| "右转" | 0x04 | 原地右旋 |
| "坐下" | 0x05 | 坐下姿态 |
| "行走" | 0x06 | 向前走 (同前进) |
| "停止" | 0x07 | 卧倒休眠 |
| "跳舞" | 0x08 | 跳舞步态 |
| "唱歌" | 0x09 | MP3 唱歌 |

**播报触发**:
```c
CI1302_Speak(CI1302_CMD, 0x81);     // CI1302 播放预存语音 0x81
CI1302_Speak(CI1302_ANNOUNCE, 0x01); // 开机播报
```

### 4.2 WT2003H4 MP3 (UART)

| 项目 | 参数 |
|------|------|
| 接口 | UART1 (PA8=TX, PA9=RX) |
| 波特率 | 115200 bps |
| 协议 | 二进制帧: `7E + 长度 + 命令 + 参数 + 校验和 + EF` |

**常用命令**:
```c
MP3_Play(n)   // 播放第 n 首 (索引模式: 0xA0 + 2字节索引)
MP3_Stop()    // 停止播放 (0xAB)
MP3_SetVol(v) // 设置音量 0-31 (0xAE)
```

**波特率配置** (UART1 时钟 4MHz → 115200):
```c
DL_UART_Main_setBaudRateDivisor(UART_1_INST, 2, 11);  // DIV=2, MOD=11
```

### 4.3 SH1106 OLED (SPI)

| 项目 | 参数 |
|------|------|
| 分辨率 | 128×64 单色 |
| 接口 | 软件 SPI (PA12=SCL, PA13=SDA) |
| 控制引脚 | PA17=RES, PA16=DC, PA22=CS |
| 缓冲 | OLED_GRAM[128][8] (1024 字节) |
| 寻址 | 页寻址模式 (SH1106 不支持水平寻址) |

**图片格式**: Image2Lcd 取模, 水平扫描, 单色, 6 字节头 `[scan][bpp][w_lo][w_hi][h_lo][h_hi]`

## 五、舵机系统

### 5.1 PWM 配置

| 参数 | 值 | 说明 |
|------|-----|------|
| PWM 频率 | 50 Hz | 标准舵机频率 |
| 定时器时钟 | 500 kHz | 预分频后 |
| PWM 周期 (ARR) | 10000 | 20ms 周期 |
| CCR 范围 | 250 ~ 1250 | 0.5ms ~ 2.5ms 脉宽 |
| 中立位 CCR | 750 | 1.5ms 脉宽 = 90° |
| CCR ↔ 角度 | `CCR = 250 + angle × 1000 / 180` | 线性映射 |

### 5.2 舵机映射与安装方向

| 通道 | 腿 | PWM 实例 | MCU 引脚 | 安装方向 | g_legInv |
|------|-----|---------|---------|---------|----------|
| ch0 | FL 前左 | PWM_1 (TIMA1) | PA15 | 齿轮朝前 (正常) | 0 |
| ch1 | FR 前右 | PWM_2 (TIMA0) | PA0 | 齿轮朝前 (正常) | 1 |
| ch2 | RL 后左 | PWM_3 (TIMG6) | PA21 | 齿轮朝后 (反装) | 0 |
| ch3 | RR 后右 | PWM_4 (TIMG0) | PA23 | 齿轮朝后 (反装) | 1 |

**反相逻辑** (`g_legInv`):
- `inv=0` (正常): `CCR = v` — 直接使用步态曲线值
- `inv=1` (反相): `CCR = 1500 - v` — 绕中立位 750 镜像

> **为什么需要反相**: FR (前右) 和 RR (后右) 的舵机齿轮朝向与其他腿不同，相同 CCR 值会导致物理运动方向相反。反相后四条腿的物理运动方向统一。

### 5.3 特殊姿态

| 姿态 | FL (ch0) | FR (ch1) | RL (ch2) | RR (ch3) |
|------|---------|---------|---------|---------|
| 中立 (归中) | 750 | 750 | 750 | 750 |
| 坐下 | 750 | 750 | 1250 | 250 |
| 卧倒休眠 | 250 | 1250 | 1250 | 250 |

## 六、步态引擎

### 6.1 核心参数

```c
#define CYCLE_STEPS     100    // 周期步数 (100步 × 5ms = 500ms/周期)
#define CYCLE_DELAY_MS  5      // 每步延时
#define SMOOTH_STEP     30     // 每步 CCR 逼近量 (越大响应越快)
#define LAG_STEPS       (CYCLE_STEPS / 2)  // 对角腿相位差 (50步 = 半周期)
```

### 6.2 步态曲线

**前进曲线** `Gait_ForwardCCR(t)`:
- 0~9 步 (10%): 快前摆 — CCR 1050→450 (向前快速摆动)
- 10~99 步 (90%): 慢后推 — CCR 450→990 (向后慢速蹬地)

**后退曲线** `Gait_BackwardCCR(t)`:
- 0~9 步 (10%): 快后摆 — CCR 450→1050
- 10~99 步 (90%): 慢前推 — CCR 1050→510

> **设计原理**: 不对称占空比 (10% 摆动 + 90% 蹬地) 模拟生物步态。快速前摆减少空气阻力时间，慢速蹬地提供推进力。

### 6.3 步态模式

| 步态 | 对角配对 | 描述 |
|------|---------|------|
| **前进** | FL+RR 领先 / FR+RL 滞后 | 对角小跑 (trot)，对角线两条腿同步 |
| **后退** | FL+RR 领先 / FR+RL 滞后 | 后退对角小跑 |
| **左转** | FL 后退+FR 前进 / RL 后退+RR 前进 | 右侧前进+左侧后退 = 原地逆时针旋转 |
| **右转** | FL 前进+FR 后退 / RL 前进+RR 后退 | 左侧前进+右侧后退 = 原地顺时针旋转 |
| **跳舞** | FL→FR→RL→RR 依次 1/4 周期 | 四相波浪传播，前后腿反相摇摆 |

### 6.4 平滑逼近算法

所有非阻塞步态使用相同的平滑插值:
```c
if (cur < target) cur += SMOOTH_STEP;  // 逐步接近目标
if (cur > target) cur -= SMOOTH_STEP;
```
这避免了瞬时 CCR 跳变导致的舵机剧烈抖动。

### 9.1 已解决

### B. OLED 图片制作 (Image2Lcd)

1. 准备 128×64 像素或更小的黑白图片 (BMP/PNG)
2. 打开 Image2Lcd → 导入图片
3. 设置: **水平扫描, 单色, 不压缩**
4. 生成 C 数组 → 替换 `LCD/img_*.h` 中的数组内容
5. 数组名必须与 include 的变量名一致 (如 `gImage_sleep`)

### C. SH1106 与 SSD1306 关键差异

| 项目 | SSD1306 | SH1106 |
|------|---------|--------|
| 列起始地址 | 0 | 2 (需 +2 偏移) |
| 水平寻址 | 支持 | **不支持** |
| 页寻址 | 支持 | 支持 (本项目使用) |
| 电荷泵寄存器 | 0x8D | 0xAD |
| 最大列数 | 128 | 132 |

### D. 调试串口命令

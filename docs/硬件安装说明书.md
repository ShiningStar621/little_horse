# 地猛星 MSPM0G3507 机器人 硬件安装说明书

## 一、引脚总表

### MCU → 外设 一览

| MSPM0 引脚 | 连接对象 | 功能 | 备注 |
|------------|---------|------|------|
| PA0 | 舵机 | PWM_2 前右腿 (FR) | |
| PA10 | 串口模块 | UART0 TX 调试输出 | 115200bps |
| PA11 | 串口模块 | UART0 RX | |
| PA12 | OLED D0 | SPI 时钟 SCL | |
| PA13 | OLED D1 | SPI 数据 SDA | |
| PA14 | 板载 LED | 状态指示 | |
| PA15 | 舵机 | PWM_1 前左腿 (FL) | |
| PA16 | OLED DC | 命令/数据选择 | |
| PA17 | OLED RES | 复位 | |
| PA21 | 舵机 | PWM_3 后左腿 (RL) | |
| PA22 | OLED CS | 片选 | |
| PA23 | 舵机 | PWM_4 后右腿 (RR) | |
| PA8 | MP3 模块 RX | UART1 TX (发数据给MP3) | |
| PB2 | CI1302 SCL | I2C 时钟 | 语音识别 |
| PB3 | CI1302 SDA | I2C 数据 | 语音识别 |

## 二、各模块接线详图

### 1. OLED 屏幕 (1.3寸 SH1106, 7针)

```
OLED 引脚          MSPM0 引脚
────────────────────────────
GND      ────     GND
VCC      ────     3.3V
D0(SCL)  ────     PA12
D1(SDA)  ────     PA13
RES      ────     PA17
DC       ────     PA16
CS       ────     PA22
```

### 2. CI1302 语音识别模块 (I2C)

```
CI1302             MSPM0 引脚
────────────────────────────
GND      ────     GND
3.3V     ────     3.3V
SCL      ────     PB2
SDA      ────     PB3
```

### 3. 舵机 (4路)

```
舵机               MSPM0 引脚    通道
───────────────────────────────────
前左腿 FL 信号 ──  PA15         PWM_1
前右腿 FR 信号 ──  PA0          PWM_2
后左腿 RL 信号 ──  PA21         PWM_3
后右腿 RR 信号 ──  PA23         PWM_4
所有舵机 VCC ────  外部 5V 电源  (独立供电!)
所有舵机 GND ────  外部电源 GND + 板卡 GND (共地)
```

> ⚠️ 舵机必须**独立供电**（外部 5V），不要从板卡 5V 取电。

### 4. MP3 模块 (WT2003H4 M09)

```
MP3 模块           连接
────────────────────────────
VCC      ────     外部 5V 电源
GND      ────     外部电源 GND + 板卡 GND
RX       ────     PA8 (MSPM0 TX)
TX       ────     不接 (可选)
```

---

## 三、电源分配

```
外部 5V 电源
    ├── 舵机 VCC (4路)
    ├── MP3 模块 VCC
    └── (不要接板卡 5V 排针)

板卡 3.3V
    ├── OLED VCC
    ├── CI1302 VCC
    └── 其他 3.3V 外设

所有模块 GND 必须共地
```

---

## 四、首次上电检查

1. 万用表量 OLED VCC-GND 间电压 = 3.3V
2. 万用表量 MP3 模块 VCC-GND 间电压 = 5V
3. 串口助手 115200bps 应看到 `Board Init...` 开机信息
4. OLED 应显示 "DMX Robot" + "Ready..."
5. 舵机短暂微动自检
